# REVIEW — base-makefile (documentation pass)

> Docs-only meta-review. Records contradictions, doc debt, and open questions
> found while documenting. **No code changed.**

## Snapshot

- Remote: `git@github.com:Forge-Stack-Workshop/base-makefile.git`
- Branch at documentation time: `_pr54feature/...` (working branch, see report)
- Purpose (FACT): composable GNU Make library (core + bricks + profiles) with a
  one-command installer, for chrysa / Forge-Stack projects.
- Smoke-test: 12/12 OK (verified 2026-09-25).

## Contradictions found

1. **`install.sh` help text lags reality.** The script header and `--profile`
   flag doc list 7 profiles (`micro|micro-container|frontend|django|fullstack|
   fullstack-container|unity`) and omit `fastapi` and `infra`, which exist on
   disk (9 total). `--list` is data-driven and correct. → doc/UX debt in the
   script comments (not fixable here — this is source).
2. **`HANDOFF.md` is stale on scope.** It lists `fastapi` and `infra` profiles
   and the `db/alembic`, `infra/*`, `docs/sphinx`, `ops/release`, `docker/build`,
   `quality/coverage-gate` bricks as "candidates / à faire", but all are now
   present in `lib/`. HANDOFF also lists only 7 profiles in its "État — FAIT".
3. **`.gitignore` vs tracked file.** `.claude/settings.local.json` is ignored
   yet tracked (see SECURITY.md finding 1).
4. **Language.** CLAUDE.md/CONTRIBUTING mandate English-only, but `HANDOFF.md`
   is written in French (it is a human handoff note; acceptable but inconsistent
   with the stated rule).

## Documentation debt

- No `MAKEFILE-STANDARD.md` copy in-repo; the authoritative standard lives in
  `shared-standards` (external). Consumers must cross-reference.
- Minimum required GNU Make version is undocumented.
- No documented functional test of brick targets against a sample project
  (only `help` dry-run parsing).

## Key UNKNOWNs

- Whether `makefile-check` runs in this repo's CI or only in `shared-standards`.
- Whether `BASE_MAKEFILE_REF` in the standard now tracks this brick library or
  the legacy flat baseline `v0.1.0-29`.

## Strengths (worth preserving)

- Clean layering + include-order contract; single `.PHONY` discipline.
- Host/container parity via `$(RUN)` with UID/GID preservation.
- Cheap, dependency-free CI gate that catches `$(shell …)` errors make hides.
- Idempotent, no-force CD release flow with the root-cause fix documented inline.
